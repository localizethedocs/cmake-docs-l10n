Step 2: Using CTest Launchers¶

This step extends Step 1 by enabling CTest launchers, which give more detailed reports of build warnings and errors.

Step2/submit.cmake¶
set(CTEST_BUILD_NAME "Step2: launchers")
site_name(CTEST_SITE)
set(CTEST_SOURCE_DIRECTORY "${CTEST_SCRIPT_DIRECTORY}/../Project")
set(CTEST_BINARY_DIRECTORY "${CTEST_SCRIPT_DIRECTORY}/build")
set(CTEST_CMAKE_GENERATOR "Unix Makefiles")
set(CTEST_NOTES_FILES "${CMAKE_CURRENT_LIST_FILE}")

set(CTEST_UPDATE_COMMAND "git")
set(CTEST_UPDATE_VERSION_ONLY 1)

# Enable CTest launchers.  This allows us to capture more granular build
# warning/error information by wrapping each build command.
set(CTEST_USE_LAUNCHERS 1)

ctest_empty_binary_directory("${CTEST_BINARY_DIRECTORY}")

ctest_start(Experimental)
ctest_update()

# Add a target that fails to compile, to show how launchers report it.
ctest_configure(OPTIONS "-DDASHBOARD_EXAMPLE_BUILD_ERROR=ON")

ctest_build()
ctest_test()
ctest_submit()

When CTEST_USE_LAUNCHERS is enabled, CTest wraps each compile, link, and custom command in a launcher. If a command produces a warning or error, CTest records its command line, working directory, and output, and includes them in the submission. Without launchers, CTest only scans the whole build output, which makes it harder to tell which command produced a given message.

To show this, the script configures the project with the DASHBOARD_EXAMPLE_BUILD_ERROR option, which adds a target whose source file calls an undeclared function:

Project/error.cxx¶
int main()
{
  // This function is not declared, so this file fails to compile.
  undeclared_function();
  return 1;
}

On CDash, the build shows the compiler command line that failed, the error message, and the source file and line. This makes triage significantly faster on large projects where a single failing compilation step may be buried in megabytes of build output.

Depending on the build tool, the build may stop at the error before it builds the test executables. In that case, the Test step reports that it cannot find them.

Launchers require that the project includes the CTest module, and that the project is configured by ctest_configure() so that CTest can add the launchers to the build system.

Requirements¶

  • A build tool supporting launchers (the Makefile Generators or Ninja Generators).

Running the Script¶

ctest -S Step2/submit.cmake -V
