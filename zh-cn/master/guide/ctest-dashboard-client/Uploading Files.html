Step 6: Uploading Files¶

This step extends Step 5 by attaching files to the build on CDash with the ctest_upload() command.

Step6/submit.cmake¶
# Bundle the logs from this run into an archive.
set(logs "${CTEST_BINARY_DIRECTORY}/logs.tar.gz")
file(ARCHIVE_CREATE
  OUTPUT "${logs}"
  PATHS "${CTEST_BINARY_DIRECTORY}/Testing/Temporary"
  FORMAT gnutar
  COMPRESSION GZip
  )

# Upload extra files to be associated with this build on CDash.
ctest_upload(FILES
  "${logs}"
  "${CTEST_SCRIPT_DIRECTORY}/cmake.url"
  )

ctest_submit()

The uploaded files appear on the build's page on CDash, where they can be downloaded. This step uploads two files:

logs.tar.gz

An archive of the logs that CTest wrote during this run, created with file(ARCHIVE_CREATE).

cmake.url

A file that contains only a URL. CDash shows it as a link.

Uploads are useful for anything that helps diagnose or reproduce a result but does not fit in the configure, build, test, or coverage reports, such as:

  • Compiler logs or linker maps.

  • Reports from other tools.

  • Installation packages.

  • Screenshots from GUI tests. CDash shows images on the build's page.

Requirements¶

  • The same as Step 3.

Running the Script¶

ctest -S Step6/submit.cmake -V
