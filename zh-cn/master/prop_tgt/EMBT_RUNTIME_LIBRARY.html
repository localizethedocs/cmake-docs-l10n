EMBT_RUNTIME_LIBRARY¶

Added in version 4.6.

Select the runtime library used by the Embarcadero (bcc64x) toolchain.

The allowed values are:

Static

Compile without additional flags to use the statically-linked runtime library.

Dynamic

Compile with -tR and define USEPACKAGES to use the dynamically-linked (shared) runtime library.

The value is ignored on non-Embarcadero compilers but an unsupported value will be rejected as an error when using the bcc64x toolchain.

If this property is not set then no runtime library selection flag is added explicitly by CMake, which is equivalent to Static.

Use generator expressions to support per-configuration specification.

For example, the code:

add_library(mylib SHARED mylib.cxx)
set_property(TARGET mylib PROPERTY EMBT_RUNTIME_LIBRARY "Dynamic")

selects for the target mylib the dynamically-linked runtime library.

This property is initialized by the CMAKE_EMBT_RUNTIME_LIBRARY variable if it is set when a target is created. It has no effect on toolchains other than EMBTClang.
