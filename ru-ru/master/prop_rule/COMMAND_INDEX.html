COMMAND_<INDEX>¶

Добавлено в версии 4.5.

Read-only property giving a semicolon-separated list of the arguments of the rule as specified by the <INDEX>``th ``COMMAND option of the add_custom_rule() command. The index range is starting at 0. If the index specified is out of the range of commands, NOTFOUND is returned.

The COMMAND rule property can be used as a shorthand to the COMMAND_0 rule property.

The number of commands can be retrieve using the COMMAND_COUNT rule property.
