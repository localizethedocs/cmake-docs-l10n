INTERFACE_FILE_SETS_<TYPE>¶

Добавлено в версии 4.5.

Read-only list of the target's INTERFACE and PUBLIC file sets of type <TYPE>.

See Also¶

Related properties:

  • FILE_SETS_<TYPE> to list the target's PRIVATE file sets

  • FILE_SET_TYPES to list the target's file set types

  • INTERFACE_HEADER_SETS to list the target's INTERFACE file sets of type HEADER

  • INTERFACE_SOURCE_SETS to list the target's INTERFACE file sets of type SOURCE

  • INTERFACE_CXX_MODULE_SETS to list the target's INTERFACE file sets of type CXX_MODULES

Related commands:

  • target_sources() to define file sets
