ctest-output-dir¶

  • ctest(1) gained an --output-dir option, and the corresponding CTEST_OUTPUT_DIRECTORY variable for Dashboard Client scripts, to specify the directory in which CTest writes its output files. Previously these were always written to the Testing directory under the build tree, which prevented running more than one ctest process against the same build tree.
