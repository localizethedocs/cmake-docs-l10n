CMP0229¶

Добавлено в версии 4.6.

The CMAKE_SKIP_INSTALL_RPATH variable takes effect at target creation.

CMake 4.5 and below apply the CMAKE_SKIP_INSTALL_RPATH variable's value at the end of each directory to every target in that directory. CMake 4.6 and above instead prefer to initialize the SKIP_INSTALL_RPATH target property from the variable as each target is created. This policy provides compatibility for projects expecting the prior behavior.

The OLD behavior for this policy ignores the value of the CMAKE_SKIP_INSTALL_RPATH variable on target creation and use its value at the end of each directory.

The NEW behavior for this policy uses the value of the CMAKE_SKIP_INSTALL_RPATH variable at target creation to initialize the SKIP_INSTALL_RPATH property. After that the target property is used instead of the variable.

This policy was introduced in CMake version 4.6. It may be set by cmake_policy() or cmake_minimum_required(). If it is not set, CMake does not warn, and uses OLD behavior.

Примечание

The OLD behavior of a policy is deprecated by definition and may be removed in a future version of CMake.
