TARGET_INTERMEDIATE_DIR¶

This generator expression belongs to the Target Artifacts family. See that section for related generator expressions.

Syntax¶

$<TARGET_INTERMEDIATE_DIR:tgt>

Добавлено в версии 4.2.

The full path to the directory where intermediate target files, such as object and dependency files, are stored.
