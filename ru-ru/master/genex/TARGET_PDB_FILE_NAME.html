TARGET_PDB_FILE_NAME¶

This generator expression belongs to the Target Artifacts family. See that section for related generator expressions.

Syntax¶

$<TARGET_PDB_FILE_NAME:tgt>

Добавлено в версии 3.1.

Name of the linker generated program database file (.pdb).

Note that tgt is not added as a dependency of the target this expression is evaluated on (see policy CMP0112).
