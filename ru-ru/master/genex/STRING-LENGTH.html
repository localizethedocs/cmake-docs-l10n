STRING:LENGTH¶

$<STRING:LENGTH,string>¶

This generator expression belongs to the String Queries family. See that section for related generator expressions.

Syntax¶

$<STRING:LENGTH,string>

Добавлено в версии 4.3.

The given string's length in bytes. Note that this means, if string contains multi-byte characters, the result will not be the number of characters.
