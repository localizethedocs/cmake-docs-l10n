SYCL_SEPARABLE_COMPILATION¶

Добавлено в версии 4.5.

Примечание

Experimental. Gated by CMAKE_EXPERIMENTAL_SYCL.

SYCL only: Enables separate compilation of device code

If set this will enable separable compilation for all SYCL files for the given target.

For instance:

set_property(TARGET myexe PROPERTY SYCL_SEPARABLE_COMPILATION ON)

This property is initialized by the value of the CMAKE_SYCL_SEPARABLE_COMPILATION variable if it is set when a target is created.
