CMAKE_TEST_BUILD_DEPENDS¶

Устарело, начиная с версии 4.5.

Добавлено в версии 4.4.

Enabling this variable previously enabled generation of test_prep/<name> build targets for tests when using Ninja Generators. Since CMake 4.5, these targets are now enabled by default. Since CMake 4.5, the CMAKE_SKIP_TEST_PREP_TARGETS may be used to disable generation of these targets.
