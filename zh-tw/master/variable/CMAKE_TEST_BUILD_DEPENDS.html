CMAKE_TEST_BUILD_DEPENDS¶

在 4.5 版之後被棄用.

在 4.4 版被加入.

Enabling this variable previously enabled generation of test_prep/<name> build targets for tests when using Ninja 生成器. Since CMake 4.5, these targets are now enabled by default. Since CMake 4.5, the CMAKE_SKIP_TEST_PREP_TARGETS may be used to disable generation of these targets.
