CMAKE_SYCL_DEVICE_TARGETS¶

在 4.5 版被加入.

備註

Experimental. Gated by CMAKE_EXPERIMENTAL_SYCL.

Default value of the SYCL_DEVICE_TARGETS target property. See that property for the supported compiler-specific values.

If set before first enabling SYCL, this variable also selects device targets for compiler identification and testing.

For AdaptiveCpp, if this variable is not defined when SYCL is first enabled, the default selection is taken from the ACPP_TARGETS environment variable, then HIPSYCL_TARGETS, or the compiler's installation default if neither environment variable is defined.

This variable is propagated into try_compile() projects.
