C_COMPILER_ID¶

This generator expression belongs to the Compiler Language, ID, and Frontend-Variant family. See that section for related generator expressions.

語法¶

$<C_COMPILER_ID>

CMake's compiler id of the C compiler used.

語法¶

$<C_COMPILER_ID:compiler_ids>

where compiler_ids is a comma-separated list. 1 if CMake's compiler id of the C compiler matches any one of the entries in compiler_ids, otherwise 0.

在 3.15 版的變更: Multiple compiler_ids can be specified. CMake 3.14 and earlier only accepted a single compiler ID.
