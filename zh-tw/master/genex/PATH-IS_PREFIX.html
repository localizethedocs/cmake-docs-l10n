PATH:IS_PREFIX¶

This generator expression belongs to the 路徑查詢 family. See that section for related generator expressions.

語法¶

$<PATH:IS_PREFIX[,NORMALIZE],path,input>

在 3.24 版被加入.

Returns 1 if path is the prefix of input, 0 otherwise.

When the NORMALIZE option is specified, path and input are normalized before the check.

An empty path is not a prefix of any input.

在 4.5 版的變更: An empty path was previously a prefix of every input. See policy CMP0223.
