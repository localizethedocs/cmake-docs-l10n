CMAKE_TEST_BUILD_DEPENDS¶

Added in version 4.5.

List of directory-scoped build time dependencies for tests.

This property holds a semicolon-separated list of targets and/or files that should be built by test_prep/all when CMAKE_TEST_BUILD_DEPENDS is enabled. A relative file path is interpreted with respect to the current source directory if the file exists there, and otherwise with respect to the current binary directory.

Projects may append to this property directly with set_property() or set_directory_properties() to extend test_prep/all with directory-scoped build dependencies.
