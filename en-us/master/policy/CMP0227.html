CMP0227¶

Added in version 4.6.

AIX shared objects are named with VERSION and SOVERSION.

On AIX, when AIX_SHARED_LIBRARY_ARCHIVE is disabled, a SHARED library target is built as a plain shared object .so file. CMake 4.5 and below ignore the VERSION and SOVERSION target properties for such files because AIX shared objects have no builtin soname, so only a single lib<name>.so file is produced. CMake 4.6 added the AIX_SHARED_LIBRARY_SYMLINKS target property to name the shared object with VERSION and create SOVERSION and unversioned symlinks to it, as on other UNIX platforms.

CMake 4.6 and above prefer, when AIX_SHARED_LIBRARY_SYMLINKS is not set, to enable versioned names and symlinks by default. This policy provides compatibility for projects that have not been updated.

The OLD behavior for this policy is to disable versioned names and symlinks when AIX_SHARED_LIBRARY_SYMLINKS is not set. The NEW behavior for this policy is to enable versioned names and symlinks when AIX_SHARED_LIBRARY_SYMLINKS is not set.

This policy was introduced in CMake version 4.6. It may be set by cmake_policy() or cmake_minimum_required(). If it is not set, CMake does not warn, and uses OLD behavior.

Note

The OLD behavior of a policy is deprecated by definition and may be removed in a future version of CMake.
