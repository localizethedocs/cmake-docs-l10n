FILE_SET_TYPES¶

Added in version 4.5.

Read-only list of the target's file set types.

See Also¶

Related properties:

  • FILE_SETS_<TYPE> to list PRIVATE and PUBLIC file sets of type <TYPE>.

  • INTERFACE_FILE_SETS_<TYPE> to list INTERFACE and PUBLIC file sets of type <TYPE>.
