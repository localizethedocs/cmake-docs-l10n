SOURCE_GROUP¶

Added in version 4.5.

Define a grouping for source files of the file set in IDE project generation.

The SOURCE_GROUP file set property take precedence over any other way to specify the grouping of source files. See the source_group() command for details.

Related properties:

  • Use SOURCE_GROUP to specify a group for the source file.

Related commands:

  • source_group() to manage various ways to specify grouping of sources.
