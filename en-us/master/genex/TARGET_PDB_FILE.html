TARGET_PDB_FILE¶

This generator expression belongs to the Target Artifacts family. See that section for related generator expressions.

Syntax¶

$<TARGET_PDB_FILE:tgt>

Added in version 3.1.

Full path to the linker generated program database file (.pdb) where tgt is the name of a target.

Changed in version 4.2: The postfix, as specified by DEBUG_POSTFIX or <CONFIG>_POSTFIX target properties, is always included in the PDB file name. See the policy CMP0202.

See also the PDB_NAME and PDB_OUTPUT_DIRECTORY target properties and their configuration specific variants PDB_NAME_<CONFIG> and PDB_OUTPUT_DIRECTORY_<CONFIG>.
