RULE_PROPERTY¶

This generator expression belongs to the Generator Expression Reference family. See that section for related generator expressions.

Syntax¶

$<RULE_PROPERTY:rule,prop>

Added in version 4.5.

Value of the property prop on the rule rule, or empty if the property is not set. An error will be raised if the rule is not known by CMake.

This generator expression can only be used in the definition of a custom rule (see add_custom_rule()). Moreover, rule parameter must be the pattern <RULE>. Any other value will raise an error.
