PATH:IS_PREFIX¶

This generator expression belongs to the Path Queries family. See that section for related generator expressions.

Syntax¶

$<PATH:IS_PREFIX[,NORMALIZE],path,input>

Added in version 3.24.

Returns 1 if path is the prefix of input, 0 otherwise.

When the NORMALIZE option is specified, path and input are normalized before the check.

An empty path is not a prefix of any input.

Changed in version 4.5: An empty path was previously a prefix of every input. See policy CMP0223.
