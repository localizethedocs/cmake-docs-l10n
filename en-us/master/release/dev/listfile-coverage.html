listfile-coverage¶

  • The CMAKE_LISTFILE_COVERAGE_DIR environment variable was added to record coverage of CMake language code in lcov tracefiles.

  • ctest(1) gained a CMAKE value for its CoverageTool setting to record coverage of CMake language code for each test.

  • The ctest_coverage() command learned to read coverage of CMake language code recorded by the CMAKE coverage tool.
